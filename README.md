# iaLingo 🥚✨

**Learn English with magical pets.** A voice-first learning game for children aged 6–10 (core 7–9). Kids hatch an original pet, play bite-sized lessons narrated by ten guide characters, listen to picture stories, **sing along**, **practice speaking with on-device speech recognition**, train in the **Word Gym**, collect a **sticker for every word**, play in the **Play Park**, and watch their pet **grow in 3D** as they learn.

No login, no ads, no purchases, and no network calls of its own: everything stays on the device.

## Run it

### Option A: Expo Go (quickest, no speech recognition)

```bash
npm install
npm run start:go        # Expo Go mode
```

Scan the QR code with Expo Go (SDK 58). Everything works except speaking exercises, which fall back to **self-check** mode ("say it out loud" + "I said it!").

### Option B: Development build (full features, including speech recognition)

The app uses one native module that Expo Go does not ship (`expo-speech-recognition`), so the full experience runs in a **development build**:

```bash
npm install
npm run build:dev:android      # EAS cloud build → install the APK on a device
# or: npm run build:dev:ios    # requires an Apple developer account
# or locally: npm run android / npm run ios   (Android Studio / Xcode)

npm run start:dev-client       # then open the installed iaLingo dev app
```

Builds are configured in `eas.json` (`development`, `development-simulator`, `preview`, `production`). The bundle id and package are `com.binnicordova.ialingo`. Native folders are generated by `expo prebuild` (Continuous Native Generation) and are not committed.

## How it plays

1. **Onboarding (under a minute):** pick a language → pick an egg → tap it until it hatches (3D) → pick a preset name. No account, email or keyboard.
2. **Adventure map:** every world and lesson on one winding path (grouped by level), the next lesson marked **Start!** with your pet beside it, each world's pet standing by its path, and **Jump here?** to open a world ahead with a quick challenge. Practice, quests, pets and badges live in the tabs below.
3. **Each world:** about 4 *learn* lessons (new words, each with one speaking exercise) → a **story** (picture book read aloud by the guide, then comprehension questions) → a **sing-along** (the guide chants each line, the child echoes it, then "which word is missing?") → a **speaking** lesson → review → the **boss** challenge, which wins that world's pet egg.
4. **Speaking practice:** the child hears the word, taps the microphone and says it. The device recognizes the speech **on the device**, and child-friendly scoring gives "Great!", "Almost, listen again" or "Try again" (up to 3 tries, never a dead end). Without a recognizer it falls back to self-check.
5. **Pets (3D):** feed, play, dress up, choose who joins the adventure; pets grow from Baby to Junior to Grown-up through learning only.
6. **Practice and play:** the **Word Gym** brings back the words that are due (unlimited, never new words); the **sticker album** shows every word met, learned and mastered; the **Play Park** has Bubble Pop, Memory Match, I Spy (find the word the guide says in a scene) and Odd One Out (three words from one category and one that doesn't belong) with learned words (game berries are capped per day); **daily quests** (always "finish lessons", plus two the child can do today) open a chest. Nothing is lost if a day is skipped.
7. **Healthy limits:** a daily limit (30 min by default). When it runs out, the pet falls asleep; a grown-up can add 10 minutes.
8. **For families:** up to 4 children, each with their own pets and progress; a "Who's playing?" picker on launch.
9. **For parents (behind the gate):** progress per world, speaking settings, the opt-in **voice diary** (a weekly 5-second voice postcard, week 1 next to today), and **certificates** for Starters / Movers / Flyers (printable; the child's name is handwritten, never stored).

## Architecture (short version)

Domain-driven, layered, dependencies pointing inward:

```
src/
  app/             expo-router routes (thin)
  presentation/    screens, components, SVG art, three.js scenes, i18n, theme
  state/           Jotai: game-state atom, selectors, action atoms, profiles, lesson session
  application/     pure commands (state, input, ctx) → { state, events }, and ports
  domain/          pure TS: curriculum, learning (Leitner, pronunciation, album), pets, economy,
                   play (mini-games), quests, wellbeing, profiles, voice diary, achievements,
                   save migrations
  infrastructure/  content data + adapters (AsyncStorage, speech, recognition, audio, files)
```

Details: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) · ADRs in [`docs/adr/`](docs/adr) · tuning in [`design/tuning.md`](design/tuning.md) · privacy in [`docs/PRIVACY.md`](docs/PRIVACY.md) · roadmap in [`docs/ROADMAP.md`](docs/ROADMAP.md).

## Privacy by design

No accounts and no personal data. Pet names are presets and profiles are identified by their pet. The app has no analytics, ads, purchases or HTTP calls of its own. Speech is recognized **on the device**; the OS vendor's online recognizer is used only if a parent allows it. Voice postcards are **off by default** and stored only in the app's private folder; turning the diary off deletes them. Location and external-storage permissions are blocked. See [`docs/PRIVACY.md`](docs/PRIVACY.md).

## Adding content

Content is data. Add a world in `src/infrastructure/content/worlds-part*.ts` (rows like `['word', '🙂', 'es', 'pt', 'fr']`), its story in `stories.ts`, its chant in `songs.ts` (each line repeats one of the world's words), its semantic category in `categories.ts`, and a reward pet in `pets.ts`. Lessons, exercises, distractors, comprehension and missing-word questions are generated. `tests/unit/content/catalog-integrity.test.ts` checks every reference and generates every lesson; `store-metadata.test.ts` keeps the store copy in sync with the numbers.
